# Windows-only: pywebview's winforms backend loads .NET through pythonnet +
# clr_loader, and the two MUST be a compatible pair. Left unpinned, pip can mix
# an older pythonnet with clr_loader>=0.2.6, which crashes at startup with
#   RuntimeError: Failed to resolve Python.Runtime.Loader.Initialize
#       from ...\pythonnet\runtime\Python.Runtime.dll
# A floor of 3.1.0 (the first release with Python 3.13/3.14 wheels) lets pythonnet
# pull a matching clr_loader via its own metadata, keeping the bundled
# Python.Runtime.dll and the native clr_loader shim in lockstep. Do NOT use an
# exact pin: pythonnet 3.0.x has no wheel for the CI's Python 3.14, so it would
# fail to install. The marker keeps it off macOS/Linux, which use WKWebView/GTK.
pythonnet>=3.1.0; sys_platform == "win32"
